# Альтанки Франківськ — мангал за містом

Сайт: https://qwert11.github.io/altanky-frankivsk/

Альтанки с мангалом и базы отдыха в пределах часа езды от Ивано-Франковска.
Точки отсортированы по километражу от Ратуши по дорогам (OSRM), у каждой —
телефон, найденная цена, что известно о туалете, рейтинг Google и источник.

Фильтры: «на природе / в застройке», зона (за городом ≥10 км, пригород до 10 км,
в черте города), «только с телефоном», «только с ценой». Карта — схема с кольцами
по 10 км и условными дорогами; у каждой точки подпись с названием, телефоном и ценой.
Кнопка «На весь экран» разворачивает карту, выход по Esc.

## Как править

Всё в одном файле `index.html`. Данные — массив `DATA` в начале `<script>`:
одна запись на место (`km` и `min` — по дорогам от Ратуши, `lat`/`lng` — координата,
`approx:true` — если координата примерная, центр села). После правки — commit и push,
GitHub Pages пересобирает страницу за минуту.
